# FORWARD: the living section

This file only ever appends. From launch onward, new preregistrations are committed here
BEFORE their results exist, and verdicts are appended when the tests conclude. The public
git history of this file is the clock: anyone can verify that the bar predates the result.

Format per entry:

```
## P-YYYY-NNN | preregistered YYYY-MM-DD
hypothesis: one line
bar: the numbers that would count as success, fixed now
verdict (appended later): what happened, with numbers | class | configs run
```

Withheld-row redactions and new kills from the private research program also land here in
public form as they clear leak review.
